# Security policy

rusolve reads model files and runs user-supplied WebAssembly hooks, so bugs in the readers or
the sandbox can be security issues.

**Please do not report security issues in public issues.** Report them privately through
GitHub: on the repository page, open **Security → Report a vulnerability**. Include the input
that triggers the problem, the command you ran, and what happened.

Supported version: the latest commit on `main`. Fixes are released there first.

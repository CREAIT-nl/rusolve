# simplex

The HiGHS dual and primal simplex (`HEkk`, `HEkkDual`, `HEkkDualRHS`, `HEkkDualRow`, `HEkkPrimal`), the basis numerics wrapper `HSimplexNla`, and the shared simplex structs. `rusolve solve` uses it by default.

## What lives here
- `ekk/`: `HEkk` (init, factor, iterate, solve, dualize, proof, debug); `solve.rs` is the driver.
- `dual/`: `HEkkDual` (assess, phases, iterate, update, solve) and `dual/multi/` (PAMI, parallel); `dual_rhs.rs`, `dual_row.rs`.
- `primal/`: `HEkkPrimal` (iterate, row, hyper, weights, report, solve).
- `nla/`: `HSimplexNla` (`nla.rs`, `product_form.rs`, `debug.rs`).
- `hsimplex.rs`, `happ.rs` (`HApp.h`), `analysis.rs`, `simplex_const.rs`, `simplex_struct.rs`, `simplex_timer.rs`, `hsimplex_debug.rs`.

## HiGHS files mirrored
`simplex/HEkk*.cpp`, `HEkkDual*.cpp`, `HEkkPrimal.cpp`, `HSimplex*.cpp`, `HSimplexNla*.cpp`, `HApp.h`, `SimplexConst.h`. The exact table is in `docs/agent/codemap.md`.

## Invariants
- Pivot-for-pivot parity with HiGHS: same Devex and dual steepest-edge weights, same tick-triggered reinversion (`synthetic_tick` is compared by the tests), same BFRT flip order.
- No FMA and no reassociation (HARD RULE in `src/lib.rs`). `HVector` keeps `count` and `index` order exactly.
- A lever (for example a new pricing variant) is an option that defaults to off; identity 20/20 must stay.

## How to test
- Golden: `cargo test --release -p rusolve-ekk --test t_dual_trace --test t_primal_trace --test t_dual_row --test t_dual_rhs --test t_nla --test t_ekk_init --test t_w5_pami`.
- Fixtures: `tests/fixtures/simplex/` (full dual and primal traces, for example `afiro.dual.jsonl`), regenerated by `tools/highs-oracle/gen_fixtures.sh`.
- LP differential against highspy: `tools/diff/simplex_diff.py`; MIP identity: `tools/bench/identity.sh`.

## Change recipes
1. A trace diverges: read the failing record (phase, iteration, field), open the C++ function in the failing doc line, compare the statement order and every constant; fix the Rust, never the fixture.
2. Add a simplex lever: add the option (`docs/skills/contrib-add-option/SKILL.md`), guard the new branch with it so the default path is byte-identical, A/B it (`docs/skills/contrib-identity-abtest/SKILL.md`).
3. Port a HiGHS routine still missing: `docs/skills/contrib-port-function/SKILL.md`; place it in the file for its C++ line range.

## Pitfalls
- Reinversion is tick-triggered; a wrong synthetic tick moves a rebuild and changes the iteration count, so a divergence far from the wrong line is usually a tick.
- The deterministic work counter in `src/work.rs` is fed from the same lines as `total_synthetic_tick_`; keep both in step when you move code.

# rusolve-ekk

The faithful Rust port of HiGHS 1.16 (EKK = `HEkk`): simplex, presolve, MIP, IPX/HiPO interior point, cuPDLP/HiPDLP, QP, the `Highs` driver and the option registry. It is the default engine behind `rusolve solve` and `rusolve mip`. Map of the code: `docs/agent/codemap.md` (generated).

## What lives here
- `src/lib.rs`: module table, naming rules, type mapping, the numerical HARD RULE. Subsystems, each with its own `AGENTS.md`: `src/simplex`, `src/presolve`, `src/mip`, `src/ipm`, `src/pdlp`, `src/qpsolver`, `src/lp_data`, `src/model`, `src/io`, `src/parallel`, `src/util`.
- `src/work.rs`: the deterministic work counter.
- `tests/`: golden tests; `tests/fixtures/`: oracle output; `benches/`.

## Invariants
- Faithful port: same algorithms, constants, control flow and data layout as `reference/HiGHS`. A body is translated statement by statement from the C++ function named in its `/// HiGHS: <File>::<Class>::<method>` doc line; an idiomatic rewrite comes only after parity and is measured.
- HARD RULE (`src/lib.rs`): no `mul_add`, no fused or reassociated float code. FMA changed the pivot path on 35 of 64 traces.
- Every file carries a `//! HiGHS source:` header and the MIT notice (`THIRD_PARTY_NOTICES.md`); the codemap is generated from those headers.
- Levers (rusolve ideas) are options that default off; new ones are wired as in `docs/skills/contrib-add-option/SKILL.md`. The default search must not move: identity 20 of 20.
- Tests may not be edited to make a translation pass; a failing golden test means the port differs from HiGHS.

## How to test
- Golden fixtures (bit-exact, no tolerances): `cargo test --release -p rusolve-ekk --lib` and `cargo test --release -p rusolve-ekk --test <name>` (names `tests/t_*.rs`, `tests/ipx_*.rs`). Committed fixtures are listed in `tests/fixtures/MANIFEST.tsv`; the rest are regenerated by `tools/highs-oracle/gen_fixtures.sh`. `RUSOLVE_REQUIRE_TARGET_FIXTURES=1` turns a missing one into a failure.
- Trace diff: the failure message names the first diverging record and the HiGHS function; for MIP run `rusolve-cli mip-trace` against `tests/fixtures/mip/*.trace` (`crates/rusolve-cli/tests/mip_trace.rs`).
- Identity: `bash tools/bench/identity.sh <reference cli> target/release/rusolve-cli` must print `IDENTICAL 20 of 20`. A/B: `python tools/bench/abtest.py` (see `docs/skills/contrib-identity-abtest/SKILL.md`).

## Change recipes
1. Port a missing HiGHS function: `docs/skills/contrib-port-function/SKILL.md` (fixture first, then translation).
2. Add an option or lever: `docs/skills/contrib-add-option/SKILL.md`.
3. Find why a solve differs from HiGHS: run the matching `tests/t_*.rs`, read the first divergence, open the C++ function it names, diff statement by statement.

## Pitfalls
- A `.cpp` longer than about 700 lines is split into a directory of Rust files, one `impl` block per contiguous C++ line range (`src/lib.rs`); look for the directory, not a single file.
- Overloads get suffixed names and C++ default arguments become explicit parameters; the doc line lists them.
- Both A/B arms of any measurement run on the same machine.
